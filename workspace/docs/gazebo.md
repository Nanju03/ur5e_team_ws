# Gazebo에서 로봇 없이 확인하기

[README로 돌아가기](../README.md) · [실제 로봇 사용법](real_robot.md)

Gazebo의 가상 UR5e·AG95로 집기, 임시 적재, 회수, 쌓기를 확인하는 절차입니다.
로봇 전원·LAN·그리퍼 USB 연결은 필요하지 않습니다.

성공한 실행의 원본 계획·전송 명령은 배치별로 자동 기록하며, 완료 후 `successful_path.zip`으로 묶습니다.
저장 위치와 재기록 절차는 **[성공 경로 저장](saved_paths.md)**에 정리했습니다.
사용자가 장애물 11번·목표 14번의 23층 전체 적재를 완료했고, 완료 로그로 확인했습니다.
첫 성공 당시에는 궤적 파일 기록이 없었으므로 다음 재실행부터 새 성공 경로를 확보합니다.

**[이웃 대각선 60가지 자동 시험](gazebo_diagonal_tests.md)**은 배치 초기화·계획·실행·성공 경로 저장을
자동 반복하고, 실패한 경우만 별도 목록으로 모읍니다. 시작 명령은 `./test_block_diagonals.sh`입니다.

기본 적층 방식은 **19층까지 위에서 내려놓기, 20층부터 측면 삽입**입니다.
적층 전에는 그리퍼와 잡은 블록이 기존 탑보다 **120mm 이상** 높은 곳에서 이동하도록 계획합니다.
수정 전 GUI와 경로는 재사용하지 말고 GUI를 다시 연 뒤 ③ 배치 초기화부터 진행합니다.

## 1. 가상 환경 실행

터미널 한 개에서 실행하고 켜 둡니다. 스크립트가 이 작업공간 환경과 ROS domain 44를 설정합니다.

```bash
cd ~/ur5e_team_ws
./start_block_gazebo.sh
```

Gazebo, RViz, 배치 선택 GUI가 함께 열립니다.
GUI 제목에 **Gazebo 물리 시뮬레이션 · ROS 44**가 표시되는지 확인합니다.
`start_block_sim.sh`는 Gazebo 없이 RViz·GenericSystem으로 확인하는 별도 환경입니다.

## 2. 블록 배치와 전체 경로 확인

1. GUI에서 원하는 **장애물**, **쌓을 칸**, **빈칸**을 선택합니다. 예: 장애물 11번·쌓을 칸 14번.
   목표 칸에는 바닥 블록 1개가 있으며, 나머지 블록이 그 위로 쌓입니다.
2. 오른쪽 설정 패널을 아래로 스크롤해 **③ Gazebo 배치 초기화 / RViz에 표시**를 누릅니다.
   이 단계에서 가상 플레이트·장애물·블록이 생성됩니다.
3. **④ 전체 경로 / 높이 확인**을 누릅니다. RViz에서 접근·임시 이동·쌓기 경로를 확인합니다.
   경로 계획 단계에서는 가상 팔을 구동하지 않습니다.

## 3. 가상 동작 실행

1. 처음에는 **단계별 확인** 모드를 선택합니다.
2. 상단 **⑤ 선택한 방식으로 가상 실행**을 누릅니다.
3. RViz에 표시된 구간을 확인하고 상단 **OK**를 눌러 각 동작을 진행합니다.
   **전체 연속 실행**은 전체 경로를 확인하고 OK를 한 번 누르면 이어서 진행합니다.
4. Gazebo에서 손가락이 블록을 집고 실제 접촉·마찰·중력으로 운반하는지 확인합니다.

11번 장애물·14번 목표의 검증 배치에서는 **10번을 1번 블록 위에 임시 적재 →
15번을 14번에 적재 → 10번을 임시 위치에서 회수해 14번에 적재**합니다.
임시 위치와 순서는 배치에 따라 자동으로 정합니다. 매 집기 전 열린 그리퍼 명령은 **0.40rad**입니다.
임시 적재는 목표 탑에 쌓은 블록 수에 포함하지 않습니다.

## 4. 중지·다시 실행·종료

- 작업 도중에는 GUI의 **중지**를 사용합니다.
- 다시 시작할 때는 **③ 배치 초기화 → ④ 경로 확인 → ⑤ 가상 실행 → OK** 순서로 진행합니다.
  ③은 Gazebo 물체를 초기 배치로 다시 만들므로, 직전 운반 후의 위치를 이어서 사용하는 절차가 아닙니다.
- 전체 종료는 시작한 터미널에서 **Ctrl+C**입니다. 중복 실행 경고가 나오면 기존 Gazebo 시작 터미널을 먼저 종료합니다.

물체가 많은 장면에서는 가상 시간이 PC 시간보다 느리게 흐를 수 있습니다.
`STACK_GAZEBO_WAITING`·`STACK_GAZEBO_SETTLING`은 완료·정착을 기다리는 상태입니다.
팔 정착 기준은 0.005rad이며, 중단 원인은 마지막 `STACK_ERROR`에서 확인합니다.

기본 정착 대기는 **가상 시간 15초**입니다. 이후에도 최근 5초 동안 오차가 충분히 감소하고 있으면
5초씩, **최대 가상 시간 45초**까지 연장합니다. 오차가 멈추거나 커지면 연장하지 않습니다.
실제 시간 300초 제한과 최신 피드백·중지 검사는 별도로 유지합니다.
`STACK_GAZEBO_SETTLE_EXTENDED`는 정착 기준을 낮춘 것이 아니라 수렴을 더 기다린다는 뜻입니다.

실행 터미널 오른쪽 위의 **로그 전체 복사**를 누르면 현재 작업의 저장 로그를 클립보드로 복사합니다.
화면에 남은 500줄 이전의 내용도 포함하며 실행 중·오류 발생 후 모두 사용할 수 있습니다.
버튼 아래에 복사 완료가 표시됩니다. 아직 작업 로그 파일이 없으면 화면에 표시된 로그를 복사합니다.

이번 정착 대기·복사 버튼 수정을 적용하려면 기존 Gazebo 시작 터미널에서 **Ctrl+C**로 종료한 뒤
`./start_block_gazebo.sh`로 다시 엽니다. 중단 후에는 **③ 배치 초기화 → ④ 경로 확인 → ⑤ 가상 실행**부터
다시 진행하며 중단 당시 블록 배치에서 처음 경로를 그대로 재실행하지 않습니다.

## 화면 없이 서버만 실행할 경우

일반적으로는 위의 기본 명령을 사용합니다. 화면 없는 자동 검사에서는 다음처럼 시작할 수 있습니다.

```bash
cd ~/ur5e_team_ws
./start_block_gazebo.sh gui:=false use_rviz:=false use_gui:=false
```

## 가상 시험 결과의 범위

장애물 11번·목표 14번은 사용자가 **Gazebo 전체 23층 적재 성공**을 확인했고, 완료 로그도 보존했습니다.
개발 과정의 세 번 운반·최종 3층 시험과 구분합니다. 실물 로봇 전체 적재를 검증한 결과는 아닙니다.
Gazebo는 명목 기구학과 시험용 물성을 사용합니다. 접촉용 목표는 잡기 0.78rad,
놓기 0.67→0.50rad이며 실물용 설정과 구분합니다.

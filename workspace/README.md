# 작업공간 설정 사본

기존 노트북에서 저장소 밖 `~/ur5e_ws`에 있던 실행 스크립트와 실물 설정을 함께 보관합니다.
다른 노트북에서는 [설치 절차](../docs/other_laptop_setup.md)에 따라 설정을 작업공간으로 복사합니다.

- `physical_setup.yaml`: 로봇 베이스 받침 16mm, 그리퍼 어댑터 0mm.
- `robot_calibration/ur5e_20261031.yaml`: 사용한 실물 UR5e의 기구학 보정 원본.
- `start_*.sh`: 기존 실행 흐름의 이식용 사본. `$HOME/ur5e_ws`, `$HOME/ws_moveit2`를 기본값으로 사용합니다.
- `moveit2_humble.repos`: 개발 노트북의 수정 없는 MoveIt 소스 8개를 정확한 커밋으로 고정합니다.
- `environment_versions.txt`: 개발 노트북에서 확인한 핵심 설치 패키지 버전입니다.

스크립트는 `UR5E_WS`와 `MOVEIT_WS`로 불러올 작업공간 경로를 바꿀 수 있습니다.
로봇·GUI·뷰어는 도메인 0, 로봇 없는 시뮬레이션은 도메인 42를 사용합니다.
추가 launch 인수는 그대로 전달됩니다. 로봇 연결 스크립트는 기존과 같이 그리퍼 드라이버를
초기화할 수 있으며, 스크립트를 업로드하거나 복사하는 것만으로 실행되지는 않습니다.

MoveIt 오버레이가 없으면 설치된 ROS Humble 패키지를 사용합니다. 현재 개발 환경과 같은
소스 구성이 필요하면 고정 manifest로 오버레이를 먼저 빌드합니다.

# P0 32개 RViz 가상 시험 — 2026-11-07

[결과 PDF](P0_32개_RViz_5분_시험결과.pdf), [전체 CSV](P0_32개_결과.csv),
[중단 항목 CSV](P0_중단항목.csv)에 32개 배치의 결과를 보관한다.

- 배치당 300초에 장면 생성·계획·충돌 검사·실행을 포함했다.
- 층수는 바닥 블록 1개를 포함한다. `highest_layer`는 놓기가 완료된 층,
  `complete_cycle_layer`는 후퇴까지 완료된 층이다.
- 21개가 5분까지 진행해 5~8층에 도달했다. 나머지 11개는 피드백 관련 검사에서 중단했다.
- 중단 분류는 관절 피드백 7개, 그리퍼 결과·관절 피드백 불일치 2개,
  팔 도착값 불일치 1개, 정지 피드백 확인 실패 1개다.
- 장애물 11 → 목표 8은 8층까지 진행했다. 전체 적층 완료 사례는 없다.

시험은 복사한 `physical_incremental_measured_fingers_v22` 코드와
ROS domain 176~179의 GenericSystem·RViz에서 최대 4개씩 병렬 실행했다.
실물 로봇에는 명령을 보내지 않았다. 실제 파지각 변동·접촉력·진동·낙하는 모사하지 않으며,
이 결과를 실물 성적으로 해석하지 않는다. 병렬 실행의 자원 경쟁이 측정 시간에 포함된다.

완료 23개를 보존한 뒤 사용자의 실물 테스트 종료 확인 후 나머지 9개를 재개했다.
전후 PC 부하가 같지 않으며, 특정 실패의 원인을 CPU 부하로 확정하지 않았다.
중단 목록은 충돌 경로 실패 목록과 구분한다.

`results.json`은 전체 기록, `cases.json`은 배치 목록, `summary.json`은 분류별 집계다.
`manifest.json`에는 원본 시험지와 코드·설정의 SHA-256이 있으며,
`resume_manifest.json`에는 재개 경위, `audit_summary.json`에는 32개 결과 대조 기록이 있다.
기록 속 개발 PC의 절대 경로는 당시 자료 위치이며 팀원 PC에서 실행할 경로가 아니다.
CSV의 `cases/` 경로는 로컬에 보존한 원시 로그를 가리킨다.

용량이 큰 원시 로그·궤적·화면·코드 스냅샷·PC 전용 시험 실행기는 포함하지 않았다.
이 폴더는 결과 보관용이며 실행 가능한 로봇 경로 라이브러리가 아니다.
실제 파지각 `0.70401rad`에 대한 별도 모델 검사 결과는
[손가락 범위 수정 검증](../finger_envelope_20261107.json)에 보관했다.

PDF 재생성에는 Python 3, PyQt5와 Noto Sans CJK KR 글꼴이 필요하다.
이 명령은 보고서만 생성하며 ROS나 로봇을 실행하지 않는다.

```bash
QT_QPA_PLATFORM=offscreen python3 generate_report.py
```

재생성하면 작성 시각과 출력 파일 해시가 바뀐다. `audit_summary.json`의 출력 파일 해시는
최초 보관본에 대한 기록이다.

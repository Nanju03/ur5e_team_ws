# 개발 검증 기록

2026-10-30부터 2026-11-01까지 이 프로젝트를 만들며 사용한 개발 스크립트,
가상 시험 설정과 결과 JSON을 보관한다. 현재 실행기는 저장소 루트의 ROS 패키지이며,
현재 사용법은 [다른 노트북 설치 안내](../../docs/other_laptop_setup.md)를 따른다.

이 폴더는 원래 `~/ur5e_ws/validation`에서 사용한 기록의 사본이다. 일부 스크립트는
당시 `/home/ksn` 경로, ROS 도메인, 설치 환경과 이전 정책에 의존한다. 이전 결과가
현재 코드나 다른 로봇의 검증 결과를 뜻하지 않는다. 로그·생성된 CDR 궤적·캐시는 제외했다.

- `recovery_*`, `xy_alignment_*`: 각각 도메인 104·105의 GenericSystem 검증 도구와 결과.
- `physical_stack_*`, `probe_*`, `mock_*`: 단계별 승인·중지·가상 쌓기 등 개발 도구.
- `*_readonly.py`: 당시 실물 상태를 읽어 진단한 도구.
- `resync_empty_gripper_controller.py`: 제어기 상태를 바꾸는 당시 복구 도구이며 일반 실행기가 아니다.
- `physical_stack_before_cache.py`: 이전 구현의 비교용 사본이며 현재 실행 코드가 아니다.

실물 실행은 `workspace/`의 시작 스크립트와 현재 GUI를 사용한다. 이 폴더의 시험 스크립트는
별도 검증 환경을 확인하고 용도·도메인·동작을 읽은 뒤에만 사용한다.
